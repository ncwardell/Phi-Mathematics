Light Corkscrew

Light runs around the ring in a corkscrew. Its magnetic field wraps the path in loops whose polarity alternates. The pattern travels with the light, so the light always sits where the field pushes inward.

Energy: the light in its corkscrew, bright head, fading tail Field loop, + polarity (pushes outward) Field loop, − polarity (pushes inward) Arrow: the inward push holding the light Breathing: + loops swell outward, − loops pull in, so the structure pulses as the corkscrew turns
